🧠 '합'이란?

화면에 깔린 9장의 카드 중, 3가지 속성(모양, 도형색, 배경색)이 모두 같거나 모두 다른 3장의 카드를 말합니다.


🚩 동시 경쟁 방식 설명

1. 모든 참가자는 동시에 9장의 카드를 보며 '합'을 찾습니다.

2. '합'을 찾았다면, 누구보다 빨리 하단의 [합! 외치기] 버튼을 누르세요.

3. 가장 먼저 누른 참가자에게만 제한 시간(타이머)이 주어지며, 카드를 선택할 권한이 생깁니다.

4. 시간 내에 정답 조합 3장을 고르면 +1점, 못 고르거나 오답이면 -1점을 얻습니다.

5. 더 이상 화면에 남은 '합'이 없다면 [결!] 버튼을 누르세요. (성공 시 +3점)
